# FunPay Auto-Confirm — Chrome Extension

Расширение для Chrome, предназначенное для автоматизации работы с неподтверждёнными заказами на FunPay.

## Возможности

1. **Подключение по Golden Key** — расширение запрашивает golden_key при первом запуске и сохраняет его. При повторном запуске браузера автоматически подключается к FunPay.
2. **Сбор неподтверждённых заказов** — расширение периодически проверяет заказы со статусом «Оплачен» и собирает те, по которым прошло 24 часа без подтверждения, в два списка:
   - **Без проблем** — заказы, где нет проблем с покупателем
   - **С проблемами** — заказы, где есть спор, претензия или другие проблемы
3. **Автоматическая отправка заявки** — когда количество собранных заказов достигает настроенного лимита, расширение автоматически открывает форму техподдержки FunPay и заполняет заявку с обоими списками.

## Установка

1. Откройте Chrome и перейдите по адресу `chrome://extensions/`
2. Включите **Режим разработчика** (переключатель в правом верхнем углу)
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку `rasshirenie` (эту папку)
5. Расширение появится в списке и добавит иконку на панель

## Как получить Golden Key

1. Откройте **funpay.com** и войдите в свой аккаунт
2. Нажмите **F12** (Инструменты разработчика)
3. Перейдите на вкладку **Application** (Приложение)
4. В левом меню найдите **Cookies → https://funpay.com**
5. Найдите cookie с именем **golden_key**
6. Скопируйте её значение

## Настройки

- **Лимит заказов для отправки** — количество собранных заказов, после которого автоматически отправляется заявка (по умолчанию: 10)
- **Интервал проверки (мин)** — как часто расширение проверяет новые заказы (по умолчанию: 30 минут)
- **Автоотправка заявки** — если включено, заявка отправляется автоматически при достижении лимита

## Как это работает

1. При первом запуске расширение запрашивает Golden Key и проверяет подключение
2. Каждые N минут (настраивается) расширение запрашивает страницу `funpay.com/orders/trade?state=paid`
3. Из HTML-страницы извлекаются заказы со статусом «Оплачен»
4. Заказы, которым больше 24 часов, классифицируются:
   - Без проблем → список 1
   - С проблемами (спор, претензия) → список 2
5. Когда суммарное количество заказов в обоих списках достигает лимита:
   - Открывается вкладка `support.funpay.com/tickets/new/1`
   - Content script автоматически заполняет форму:
     - Ник продавца
     - Номер первого заказа
     - Роль: «Продавец»
     - Тема: «Покупатель забыл подтвердить»
     - Текст: оба списка заказов
   - Форма автоматически отправляется
6. После успешной отправки собранные заказы очищаются

## Технические детали

- **Manifest V3** — расширение использует современный стандарт Chrome Extension Manifest V3
- **Авторизация** — golden_key сохраняется в `chrome.storage.local` и передаётся в Cookie-заголовке при запросах к funpay.com
- **API FunPay** — расширение использует стандартные веб-страницы FunPay (`/orders/trade`), парсит HTML для извлечения данных о заказах
- **Support API** — форма техподдержки `support.funpay.com/tickets/new/1` заполняется через content script
- **Периодическая проверка** — использует `chrome.alarms` API для регулярной проверки заказов

## Безопасность

- Golden Key хранится локально в браузере и не передаётся третьим лицам
- Все запросы идут напрямую к funpay.com и support.funpay.com
- Расширение не собирает и не передаёт никаких данных на сторонние серверы
